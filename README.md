# Project-Sentinel

The goal of this project is to determine the best possible locations for a fixed number of sensors in a two-dimensional space to maximize coverage of defined priority areas, while minimizing overlap and sensor cost.

**Objectives**

1. To design an optimization algorithm for sensor placement.
2. To ensure maximum coverage of priority areas.
3. To minimize overlap between sensor ranges.
4. To visualize the optimized deployment graphically.
   
**Tools and Libraries Used**

Python — core language
NumPy — numerical computations
Matplotlib — visualization of results
OR-Tools (CP-SAT) — constraint programming solver
